# daniel-skills (v1.4)

Skills operacionais para o Claude Code: backup/restore do Firestore, design system e geração de proposta comercial / oferta produtizada do Bora Automatizar.

## Skills disponíveis

- `/dh-firestore-backup` — Exporta collections do Firestore para um arquivo JSON local
- `/dh-firestore-restore` — Restaura dados no Firestore a partir de um arquivo JSON de backup
- `/dh-designer-system-ba` — Aplica o design system real do Bora Automatizar em 3 modos (Landing Page, Sistema/App, Oferta/Produto)
- `/dh-proposta-comercial` — Gera proposta comercial em HTML single-file no padrão visual Bora Automatizar
- `/dh-oferta-produtizada` — Gera landing page de oferta produtizada (escassez, cases, FAQ) no padrão visual mais recente da marca

Cada skill tem seu próprio SKILL.md na subpasta.
