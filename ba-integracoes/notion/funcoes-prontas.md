# Notion — 8 Funções Prontas

## 1. Registrar lead num database

```
No database "CRM Leads" do meu Notion, cria uma página nova com:
- Nome: Pedro Fulano
- Telefone: 5521999999999
- Origem: WhatsApp
- Status: Novo
- Data de entrada: hoje
- Próximo contato: amanhã
```

## 2. Atualizar status

```
No database "CRM Leads", procura o lead com nome "Pedro Fulano"
e muda o Status pra "Qualificado". Adiciona uma nota:
"Confirmou interesse no plano premium em 24/05".
```

## 3. Gerar ata de reunião

```
Cria uma página dentro de "Atas de Reunião" chamada
"Reunião Pedro Fulano - 24/05/2026" com a estrutura:

## Participantes
## Contexto
## Decisões
## Próximos passos
## Owner / Prazo

Preenche com base nesse áudio/anotação: [colar transcript].
```

## 4. Buscar conhecimento interno

```
Busca no meu Notion páginas que falem sobre "política de reembolso".
Me resume o que cada uma diz em 1 parágrafo.
```

## 5. Salvar SOP / procedimento operacional

```
Cria uma página dentro de "SOPs" chamada "SOP - Atendimento Cliente VIP"
com a estrutura padrão de SOP (objetivo, escopo, dono, passos, métrica, revisão).

Preenche com base nesse texto: [colar conteúdo].
```

## 6. Diário do dia

```
Cria uma página "Diário 2026-05-24" dentro de "Diário Pessoal" com:

## Hoje farei
[3 prioridades]

## Fiz
[deixa em branco, atualizo no fim do dia]

## Aprendi
[deixa em branco]
```

## 7. Resumo semanal automático

```
Lista todas as páginas criadas/atualizadas no meu Notion nos últimos 7 dias.
Me devolve um resumo executivo em 5 bullets: o que avancei, o que parou,
o que falta decidir.
```

## 8. Knowledge base pra atendimento

```
No database "Knowledge Base", cria uma página com a pergunta:
"Como funciona a garantia do produto X?"

Resposta: [colar resposta padrão].

Marca como "Verificado" e atribui ao Suporte.
```

## Combo com WhatsApp

```
Roda a skill whatsapp-atendente nas conversas de hoje. Pra cada lead QUENTE,
cria uma página no database "CRM Leads" do Notion com:
- Nome, telefone
- Resumo da conversa
- Próximo passo sugerido
- Status: Novo
```
